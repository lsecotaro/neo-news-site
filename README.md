# Neo News — publicación estática

Portada personal de noticias de Argentina, mercados, dólar e inteligencia artificial, con clima local opcional y una interfaz inspirada en Matrix.

Este repositorio contiene únicamente la publicación estática generada. Las noticias se actualizan automáticamente una vez por hora mediante GitHub Actions.

## Sitio

- GitHub Pages: https://lsecotaro.github.io/neo-news-site/
- Dirección principal: https://leosecotaro.com.ar/neo-news/

## Contenido

- `index.html`: portada pre-generada.
- `static/`: estilos y comportamiento del navegador.
- `data/dashboard.json`: datos normalizados de la última actualización.
- `robots.txt` y `sitemap.xml`: metadatos de indexación para la dirección principal.

## Importante

- No editar este repositorio manualmente: cada publicación automática puede actualizar sus archivos.
- No contiene secretos, credenciales, herramientas administrativas ni código de scraping.
- Los artículos y cotizaciones pertenecen a sus fuentes originales, enlazadas desde la portada.
